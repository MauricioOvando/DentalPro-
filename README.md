DentalPRO es una aplicación móvil nativa para Android, desarrollada en Kotlin con Jetpack Compose, que digitaliza y centraliza la gestión comercial de un proveedor de insumos dentales. El sistema permite a clientes profesionales —dentistas y clínicas— explorar el catálogo de productos, gestionar su carrito, realizar pedidos y hacer seguimiento en tiempo real, mientras otorga al administrador un panel de control completo para operar el negocio desde el mismo dispositivo.
